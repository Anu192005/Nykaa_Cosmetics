Mini Project Title:
AI POWERED BRAND RECOMMENDATION SYSTEM
•	Why Did I choose this project?

o	I chose this project because of my interest in AI-driven recommendations and user-centric applications. Brand selection is often overwhelming for consumers, and I wanted to build a system that simplifies decision-making using Google’s Generative AI (Gemini API).

o	Generally, girls often find difficulty in finding the right makeup that is preferred for their skin based on budget, skin Colour and skin type etc

o	This Mini Project will help anyone finding the right brand for them.

•	Project Overview

o	This project leverages Gradio and Google Generative AI (Gemini API) to create an interactive brand recommendation system. The system takes user preferences and provides personalized brand suggestions based on AI-driven insights.

•	Approach & Logic

o	Implemented Gradio for an intuitive and user-friendly interface. 
o	Integrated Gemini API to process user inputs and generate brand recommendations. 

o	Used Python for backend processing and API requests. 

o	Ensured seamless interaction between UI and AI model for real-time results.

o	Used pyautogui and selenium for web scraping

•	Challenges Faced & Solutions

o	API Integration Issues: Faced authentication and response formatting challenges, resolved by refining API request handling and error management.
	As well as when I used OpenAI initially I ran out of free testing and it was asking to pay to use further.
	Thus, I shifted to Gemini AI for Api key.

o	Generating Relevant Brand Recommendations: The AI sometimes produced irrelevant or generic recommendations.
	Improved prompt engineering techniques to ensure that the AI-generated responses were more accurate, specific, and personalized.

o	UI Performance: Optimized Gradio’s components to ensure smooth user interaction.

•	Parts of the Workshop that I applied:
o	Automation using : pyautogui & selenium
o	UI : Gradio
o	AI/ML : Gemini API 

•	Future Enhancements

o	Enhance Personalization: Train a custom model or fine-tune the AI to provide even more accurate brand suggestions.

o	Expand Brand Categories: Integrate more industries, such as electronics, fashion, and home appliances. 

o	Implement User Feedback Mechanism: Allow users to rate recommendations, helping refine future responses.
